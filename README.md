# Explorador de Fractais Mandelbrot & Julia

Um explorador interativo de fractais inspirado no 3Blue1Brown.

## 🎨 Funcionalidades

- **Conjunto de Mandelbrot** - Clique para definir o parâmetro c do Julia
- **Conjunto de Julia** - Visualização em tempo real
- **Cores Suavizadas** - Gradientes HD com anti-aliasing
- **Controles Linkados** - Sincronize zoom, pan, cores e iterações
- **Compartilhamento** - URLs com todos os parâmetros embutidos

## 🚀 Como usar

1. Abra o arquivo \"fractal_explorer.html\" em qualquer navegador moderno
2. Clique no Mandelbrot para ver o Julia correspondente
3. Use scroll para zoom e arraste para mover
4. Experimente diferentes esquemas de cores (Fire, Ocean, Forest, etc.)

## 🔗 Compartilhar

Clique em \"Gerar Link\" para criar uma URL única com sua configuração atual.

## 📐 Tecnologias

- HTML5 Canvas
- JavaScript vanilla
- Algoritmo de suavização de cores (continuous iteration count)
- Resolução HD (800x800)

## 🇧🇷 Português

Um explorador interativo de fractais inspirado no [3Blue1Brown](https://www.youtube.com/watch?v=LqbZpur38nw).

### 🎨 Funcionalidades

- **Conjunto de Mandelbrot** - Clique para definir o parâmetro c do Julia
- **Conjunto de Julia** - Visualização em tempo real
- **Cores Suavizadas** - Gradientes HD com anti-aliasing
- **Controles Linkados** - Sincronize zoom, pan, cores e iterações
- **Compartilhamento** - URLs com todos os parâmetros embutidos
- **Resolução HD** - 800x800 pixels com suavização contínua

### 🚀 Como usar

1. Abra o arquivo `fractal_explorer.html` em qualquer navegador moderno
2. Clique no Mandelbrot para ver o Julia correspondente
3. Use scroll para zoom e arraste para mover
4. Experimente diferentes esquemas de cores (Fire, Ocean, Forest, etc.)

### 🔗 Compartilhar

Clique em "Gerar Link" para criar uma URL única com sua configuração atual. O link inclui:
- Posição e zoom dos dois fractais
- Parâmetro c do conjunto de Julia
- Esquema de cores e número de iterações

### 📐 Tecnologias

- HTML5 Canvas
- JavaScript vanilla (sem dependências)
- Algoritmo de suavização de cores (continuous iteration count)
- Resolução HD (800x800)

<a name="english"></a>
## 🇺🇸 English

An interactive fractal explorer inspired by [3Blue1Brown](https://www.youtube.com/watch?v=LqbZpur38nw).

### 🎨 Features

- **Mandelbrot Set** - Click to set the Julia set's c parameter
- **Julia Set** - Real-time visualization
- **Smooth Colors** - HD gradients with anti-aliasing
- **Linked Controls** - Synchronize zoom, pan, colors and iterations
- **Sharing** - URLs with all parameters embedded
- **HD Resolution** - 800x800 pixels with continuous smoothing

### 🚀 How to Use

1. Open `fractal_explorer.html` in any modern browser
2. Click on the Mandelbrot set to see the corresponding Julia set
3. Use scroll to zoom and drag to pan
4. Try different color schemes (Fire, Ocean, Forest, etc.)

### 🔗 Sharing

Click "Generate Link" to create a unique URL with your current configuration. The link includes:
- Position and zoom of both fractals
- Julia set's c parameter
- Color scheme and iteration count

### 📐 Technologies

- HTML5 Canvas
- Vanilla JavaScript (no dependencies)
- Color smoothing algorithm (continuous iteration count)
- HD Resolution (800x800)
